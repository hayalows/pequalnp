# L-lib-123 construction and definitions audit

The exact statement is ∃ p q : ℕ, 1 ≤ p ∧ p < q ∧ PEqualNP.Library.FP3 p q. This analysis establishes several supporting facts and an oracle barrier. It does not prove or disprove the unrelativized statement.

## What the exact Lean definitions require

PEqualNP/Defs/TimeAlt.lean defines FP3 with the same p and q for every language. A language has a fixed FinTM2 machine and constant D deciding it in time D·2^(q n)+D. Its proposed target may choose a language-dependent witness constant K and a deterministic relation-decider constant A. Both are independent of the input and its length. Alt 3 expands to existential, universal, existential on three bit strings of exactly K·2^(p n)+K bits each. The verifier receives the input and the concatenation of all three blocks in a tagged pair encoding of length n+3(K·2^(p n)+K). It must decide the relation in time Aℓ+A on every encoded pair of length ℓ, even malformed proof lengths.

ExactAlt.lean checks the expansion, concatenation and pair lengths, nonabsorption of strict exponential gaps by multiplicative/additive constants, and the arithmetic behind L122. Given p<q, v=7p+1 and u=v+1 satisfy p·u³<q·v³, so any proof of the assigned fixed pair would unlock a genuinely superlinear separation via checked L122. None of these arithmetic consequences proves FP3.

Mathlib's FinTM2 fixes finite sets of stack indices, labels and internal states. It requires the input alphabet finite, and the decision output alphabet equivalent to Bool. Ambient internal alphabet types can be infinite. However, a push symbol is the image of the finite control state under a function fixed at one syntactic push instruction. Every instruction tree and the set of labels are finite. Only finitely many symbols can therefore enter each internal stack, uniformly in the input. InternalAlphabet.lean checks the finite reachable-symbol theorem for exact Mathlib transitions. StackBudget.lean checks a fixed per-machine bound on stack-length growth in one transition. Arbitrary Lean functions on each reachable finite state/symbol domain can be replaced by finite transition tables. Finite-stack and standard multitape machines simulate each other up to constants by representing a tape as two stacks and a stack as a tape with its head at the current top. The canonical output requirement to clear stacks and reset state at the end can be met with linear overhead at these time scales. Hence the definitions do not create an oracle or random-access shortcut.

## One effective oracle that defeats every fixed exponent gap

Use a standard relativized multitape model where an oracle query is a finite string explicitly written or otherwise copied into the query tape. The length available to a verifier is at most a machine-dependent constant times its time plus its initially supplied input length. Define q_p(n)=2^(p n+floor(n/2)) and A-language L_p^A to accept exactly when the unary string of q_p(n) zeroes lies in oracle A. The deterministic decider writes that query in polynomial-in-n overhead per query bit using a binary counter, so its running time is O(2^((p+1)n)) and then O(2^(q n)) for every integer q>p.

Fix p, a candidate relation machine, and constants K,A for its exact block length and linear verifier clock. On input length n the verifier sees at most n+3(K·2^(p n)+K) input bits, with a fixed constant-factor affine upper bound on any query length. For sufficiently large n, its every query on every branch is shorter than q_p(n). ExactAlt.lean proves the elementary fresh-length inequality for arbitrary constants and prior assigned lengths.

Enumerate all candidates, including p, the verifier and both constants. At each stage choose n with q_p(n) longer than all previously fixed oracle lengths and longer than every query in this candidate's clocked run at length n. Fix all currently unassigned shorter strings to zero. Enumerate the three finite witness domains and evaluate the candidate's alternating result on a fixed n-bit input using these answers. Assign the q_p(n)-zero string the opposite answer, and fix all other strings of that same length to zero. This defeats the candidate without affecting any earlier stage. All choices and finite simulations can be done effectively, so the resulting oracle may be recursive, with no useful deterministic running-time bound on its membership algorithm. This proves simultaneous failure of all p<q in the explicitly relativized model. Replacing a one-step oracle call by a computation of its membership can exceed the deterministic time bound, so this is not an unrelativized refutation.

## Checkpointing with genuinely sub-time working space

For computations with time T and configuration-bit size S, choose B intervals and give B+1 complete configurations as the first existential block. The universal block selects an interval or boundary to check. The final existential block can be ignored. A fixed verifier reads the committed configurations and checks one selected T/B-step segment, including initial and terminal boundary conditions. The budget is approximately max(BS,T/B), plus polylogarithmic overhead. For T=2^(q n) and S=O(2^(r n)), r<q, choose B with exponent (q−r)/2 and absorb slack in a target p>(q+r)/2. Full-time space r=q makes the same estimate at least T, and providing additional existential data after selecting the interval does not supply a new universal check.

Ryan Williams's time-to-square-root-space theorem cannot be plugged into the timed checkpoint routine. Its Cook–Mertz low-space evaluation can take exponential time in block length. The general reduction from space S to unbounded alternating time O(S²) at S≈√(T log T) also gives at least T within logarithmic factors, not a constant power saving. Williams explicitly leaves a constant-power saving with even unbounded alternation as an open direction in Section 5, while citing a logarithmic saving. [Simulating Time With Square-Root Space](https://people.csail.mit.edu/rrw/time-vs-space.pdf)

Another obstacle is that a stack's LIFO dependence edges support noncrossing book-layout pages, but bounded page count does not imply small undirected separators. Dujmović, Sidiropoulos and Wood give bounded-degree 3-page expanders. A directed ancestor property is more specific, but Wittcop gives constant-page layered pushdown DAGs requiring Ω(N/log N) deletions even to make all ancestor cones smaller than a small fixed fraction of N. The latter does not rule out a better structural result for the actual computation graphs of some machine per language. [Layouts of Expander Graphs](https://arxiv.org/abs/1501.05020) · [Pushdown Graphs Without Small Segregators](https://www.academia.edu/181369785/Pushdown_Graphs_Without_Small_Segregators)

## Conditional construction via succinct honest tableaux

A genuine source of possible nonrelativization is a small circuit for the complete honest tableau of the ordinary fixed machine. For a deterministic time-2^(q n) multitape program, the bit language of its tableau can be addressed by the original input x plus a binary time index, tape index, binary position and record-field selector. The encoding length is O(q n) for addresses that matter. For fixed q this bit language is in E by direct simulation. The tableau may include state and head-position records, plus the contents of all visited tape cells at each time. A universal binary address can select any initial-condition, transition or final-condition check.

Assume these specific trace-bit languages have circuits of size 2^o(m) on m-bit query inputs. Existentially guess a circuit for the tableau specialized to x, pad the encoding into the first quantified block, and use the universal block for one address challenge. The chosen circuit is fixed before the challenge. A verifier evaluates the circuit at the relevant cells, head positions, state and immediate neighbor times, then checks the finite transition relation. Initial and final conditions have corresponding challenges. The true tableau is the unique one satisfying all checks, since each update is deterministic and the initial configuration is fixed. Invalid challenge addresses can accept. The third existential block can be ignored.

The verifier can use a bounded computation clock linear in the full proof input even when the candidate circuit is malformed. Circuit evaluation on a fixed multitape machine has a polynomial overhead in the circuit encoding length, and on true short certificates every challenge fits an exponential block budget with any fixed positive exponent for large n. The finite small lengths can be handled by increasing constants. All steps use the actual finite transition table, with no black-box long oracle answers. The circuit-size premise is unproved and does not follow from a short description of the machine or its run, since a short description gives no guarantee of fast random access to a late bit. Ordinary PCP and sum-check constructions also require a consistent commitment to the long shared proof or many rounds, so short independent local replies do not fill this premise.

No complete FP3 proof, unrelativized refutation, or artifact eligible for submission was obtained.
